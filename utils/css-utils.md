# CSS Utils

## В этом проекте есть четыре вспомогательных скрипта для работы с CSS-переменными:

---

## utils/css-variables-delete-unused.js

Удаляет неиспользуемые CSS custom properties (переменные) по всему проекту.

### Что делает:

- Находит все определённые CSS-переменные в \*.css файлах.
- Проверяет их использование во всех исходниках проекта (кроме _.css и _.css.map).
- Удаляет строки с определением неиспользуемых переменных из всех \*.scss файлов.
- В конце выводит отчёт: какие переменные и из каких файлов были удалены.

### Запуск:

```
node ./utils/css-variables-delete-unused.js
```

---

## utils/css-variables-rename.js

Переименовывает CSS-переменную во всех исходниках: меняет как определение, так и использование.

### Что делает:

- Переименовывает все вхождения var(--old-var) на var(--new-var) во всех исходниках (кроме _.css, _.css.map).
- Переименовывает определение --old-var: ... на --new-var: ... во всех scss-файлах.
- Показывает подробный отчёт о количестве переименований и файлах.

### Запуск:

```
node ./utils/css-variables-rename.js -from --old-var -to --new-var
```

Например:

```
node ./utils/css-variables-rename.js -from --color-bg-dark -to --color-primary
```

Запуск через npm с параметрами, начинающимися с двойного дефиса (`--`), не поддерживается из-за особенностей npm.

---

## utils/css-variables-check.js

Анализирует использование CSS custom properties (переменных) в проекте.

### Что делает:

- Находит все var(--_) во всех исходниках (кроме _.css, \*.css.map).
- Сравнивает найденные переменные с определёнными в variables.scss.
- Показывает:
  - Все используемые переменные и где они используются (файл, строка).
  - Неиспользуемые переменные из variables.scss (файл, строка).
  - Переменные, которые используются, но не определены в variables.scss.
  - Дубликаты значений переменных.
- Цветной вывод для удобства.

### Запуск:

```
npm run css:variables:check
```

---

## utils/css-variables-change.js

Массово заменяет одну CSS-переменную на другую во всех исходниках и удаляет старое определение из variables.scss.

### Что делает:

- Заменяет все вхождения var(--old-var) на var(--new-var) во всех исходниках (кроме _.css, _.css.map).
- Удаляет строку определения --old-var из variables.scss.
- Показывает подробный отчёт о количестве замен и файлах.

### Запуск:

```
node ./utils/css-variables-change.js -from --old-var -to --new-var
```

Например:

```
node ./utils/css-variables-change.js -from --color-text-light -to --color-light
```

Запуск через npm с параметрами, начинающимися с двойного дефиса (`--`), не поддерживается из-за особенностей npm.

---

## Примечания

- Оба скрипта используют Node.js (ESM).
- Перед массовыми заменами рекомендуется сделать резервную копию или использовать git.
