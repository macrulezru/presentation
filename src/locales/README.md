# 🧩 Механизм автозамены плейсхолдеров в i18n

В этом каталоге реализованы два механизма плейсхолдеров для строк локализации:

1. **Символьные плейсхолдеры** — для безопасного хранения спецсимволов (например, `@`).
2. **HTML-плейсхолдеры** — для оборачивания части строки в HTML-тег с кастомным CSS-классом прямо из локали.

---

## 1. Символьные плейсхолдеры

Используются для хранения спецсимволов в JSON. В рантайме функция `restorePlaceholders` заменяет их на реальные символы.

### Таблица соответствий

| Плейсхолдер | Замена |
| ----------- | ------ |
| `__PH:AT__` | `@`    |

Добавлять новые — через `PLACEHOLDER_MAP` в [src/locales/index.ts](src/locales/index.ts).

---

## 2. HTML-плейсхолдеры для тегов и классов

Позволяют обернуть любое слово/фразу в HTML-тег с нужным CSS-классом прямо в строке локали.

### Формат

```
__PH:BLOCK:TAG:CLASS__текст__PH:BLOCK:TAG__
```

- `TAG` — HTML-тег (например, DIV, SPAN, MARK)
- `CLASS` — CSS-класс (например, highlight, custom-class)
- `текст` — содержимое для обёртки

### Пример строки

```
"Это __PH:BLOCK:SPAN:highlight__важное__PH:BLOCK:SPAN__ слово"
```

### Как работает

- В рантайме парсер ищет такие плейсхолдеры и заменяет их на HTML-теги с нужным классом.
- Класс можно переопределить через объект `classes`, передаваемый в `t()`.

### Пример вызова t()

```js
t('key', { classes: { highlight: 'my-custom-class' } });
```

### Пример результата

Исходная строка:

```
"Это __PH:BLOCK:SPAN:highlight__важное__PH:BLOCK:SPAN__ слово"
```

Результат:

```
Это <span class="highlight">важное</span> слово
```

Если передан объект с классами:

```
t('key', { classes: { highlight: 'my-custom-class' } })
```

Результат:

```
Это <span class="my-custom-class">важное</span> слово
```

---

## Как добавить новый HTML-плейсхолдер

1. Используйте нужный формат в строке локали.
2. (Опционально) Передайте объект classes в t(), чтобы подменить CSS-класс.
3. Строка автоматически преобразуется в HTML при выводе.

---

## Почему это нужно

- Позволяет гибко выделять части текста в UI без ручного разметки в коде.
- Удобно для выделения, подсветки, кастомизации прямо из локалей.
