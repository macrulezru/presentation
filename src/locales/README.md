# 🧩 Механизм автозамены плейсхолдеров в i18n

Этот каталог использует плейсхолдеры внутри JSON-файлов локализаций, чтобы избежать проблем парсинга специальных символов (например, `@`). В рантайме placholders восстанавливаются в реальные символы в обёртке над `t` из [src/locales/index.ts](src/locales/index.ts).

## Как это работает

- В JSON-строках храним безопасные плейсхолдеры.
- В рантайме функция `restorePlaceholders` заменяет их на реальные символы перед отдачей строки в UI.
- Карта соответствий задаётся в `PLACEHOLDER_MAP` в [src/locales/index.ts](src/locales/index.ts).

## Таблица соответствий

| Плейсхолдер | Замена |
| ----------- | ------ |
| `__PH:AT__` | `@`    |

## Как добавить новый плейсхолдер

1. Добавьте новое соответствие в `PLACEHOLDER_MAP` в [src/locales/index.ts](src/locales/index.ts).
2. Используйте этот плейсхолдер в строках локалей (файлы `*.json` в этой папке).
3. Пересоберите проект (`npm run build`) и убедитесь, что UI отображает восстановленные символы.

## Почему это нужно

Некоторые символы могут вызывать ошибки при обработке или сборке локалей. Плейсхолдеры позволяют хранить строки в безопасном виде и восстанавливать их только при показе пользователю.
