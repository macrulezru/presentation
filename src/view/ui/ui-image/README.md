# UiImage — универсальный компонент для адаптивных изображений

Компонент `UiImage` предназначен для удобного вывода адаптивных изображений с поддержкой разных размеров, форматов и медиазапросов. Позволяет задавать отдельные параметры для desktop, tablet и mobile, а также aspect-ratio.

## Пропсы

| Название | Тип            | Описание                                         |
| -------- | -------------- | ------------------------------------------------ |
| image    | `UiImageProps` | Объект с параметрами для всех брейкпоинтов и alt |

### UiImageProps

```ts
interface UiImageSource {
  src: string; // Ссылка на изображение
  width?: string | number; // Ширина (px, %, auto и т.д.)
  height?: string | number; // Высота (px, %, auto и т.д.)
}

interface UiImageProps {
  src: UiImageSource; // Desktop-изображение (обязательно)
  alt?: string; // Альтернативный текст
  tablet?: UiImageSource; // Планшетная версия (опционально)
  mobile?: UiImageSource; // Мобильная версия (опционально)
}
```

## Пример использования

```vue
<template>
  <UiImage
    :image="{
      src: { src: '/img/desktop.jpg', width: 600, height: 400 },
      tablet: { src: '/img/tablet.jpg', width: '100%', height: 300 },
      mobile: { src: '/img/mobile.jpg', width: '100vw', height: 200 },
      alt: 'Описание изображения',
    }"
  />
</template>
```

## Особенности

- Для каждого брейкпоинта можно задать свою ширину и высоту (px, %, auto и т.д.).
- Для `<img>` и `<source>` применяется только ширина и aspect-ratio (высота не выставляется напрямую).
- aspect-ratio вычисляется автоматически из width и height через функцию getAspectRatioStyle.
- До загрузки изображения inline-стили width/aspect-ratio применяются к `<img>`, после загрузки — убираются.
- Если указаны только src, будет использоваться только одно изображение.
- Атрибут alt обязателен для доступности.

## Слоты и события

- Слотов и событий нет — компонент полностью управляемый через пропсы.

## Стилизация

- Класс `.ui-image` применяется к `<img>`. Для кастомизации используйте SCSS-файл `ui-image.scss`.
